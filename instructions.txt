 # Wargame – Academic Java Project

## Project Setup Instructions

Please create the following project structure and generate all listed Java files as empty classes (one public class per file, matching the filename). Each class should include the comment: `// To be implemented`.

Also, create a minimal `pom.xml` file for building the project with Maven and support for Java Swing.

## Technical constraints

- Programming language: Java
- Build tool: Maven
- GUI: Swing
- Follow SUN/Oracle Java coding conventions
- Use Javadoc for documentation
- Must be executable via a `.jar` file (no IDE required)

## Asset Structure
The game uses the following asset structure:
- src/main/resources/assets/
  - units/     # Unit sprites
  - terrain/   # Terrain textures

Each unit type has its own sprite:
- Infantry: guerrier1.png
- Heavy Infantry: guerrier2.png
- Cavalry: chevalier1.png
- Archer: archer1.png
- Mage: mage1.png

Each terrain type has its own texture:
- Plain: grass01.png
- Forest: foret3.png
- Mountain: motagne3.png
- River: riviere3.png
- Road: grass01.png (uses plain texture)
- Desert: desert3.png
- Swamp: mer3.png

Default images:
- Unknown unit: ptInterrogation.png
- Unknown terrain: grass01.png
